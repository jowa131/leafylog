leafylog

AI가 내 식물의 건강을 분석하는
로컬 퍼스트 식물 관리 다이어리

v1.0.0 · Android 설치 파일 다운로드 (APK)

leafylog-latest.apk · Android 7.0(API 24) 이상

설치 전 확인 사항
APK 설치를 위해 기기의 설정 → 보안 → 출처를 알 수 없는 앱 허용을 활성화해야 한다. 설치 후에는 보안을 위해 다시 해제하는 것을 권장한다.
Release Notes
M1 · 프로젝트 스캐폴딩 기반
  • Flutter 3.41 + Riverpod 2.4 기반 아키텍처 구성
  • Hive 로컬 NoSQL DB 초기화 및 어댑터 연동
  • flutter_dotenv를 이용한 API 키 환경 분리
  • GoRouter 기반 페이지 라우팅 체계 수립
M2 · 로컬 데이터 저장 스토리지
  • plants.json / history_log.json 파일 기반 CRUD 구현
  • UUID v4 식물 ID 자동 발급 및 소프트 삭제(아카이브) 지원
  • 사진 촬영·갤러리 선택 후 자동 압축 저장 (≤1.5 MB, 최대 2048 px)
  • AppSettings / CacheEntry Hive 모델 구현
M3 · Gemini AI 연동 AI 분석
  • Gemini 1.5 Flash 멀티모달 API 호출 (이미지 + 프롬프트)
  • 식물 종명·관리 경과일·최근 이벤트를 컨텍스트로 주입하여 오인식 방지
  • 지수 백오프 재시도 (1 s → 2 s → 4 s, 최대 3회)
  • AI 응답 JSON 자동 파싱 → 건강 점수·이슈·권장사항 저장
  • 파싱 실패 시 원시 응답을 history_log에 보존
M4 · QA 및 릴리즈 빌드 배포
  • D-Day 계산·JSON 파싱 순수 함수 단위 테스트 17건 통과
  • ProGuard/R8 난독화 + split-debug-info 적용 릴리즈 APK 빌드
  • android:allowBackup 활성화로 Google One Backup 지원
